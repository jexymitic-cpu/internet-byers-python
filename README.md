# Python Customer Management System

## About the Project
This is a beginner Python project created as part of my AI & Machine Learning studies at ITAcademy.

The program manages customer information, records purchases, calculates total spending, and determines customer status based on purchase activity and spending.

## Features
- Enter customer first and last name
- Record the number of purchases
- Enter and calculate purchase amounts
- Add new purchases using a loop
- Calculate total spending
- Check customer purchase activity
- Determine whether a customer is a VIP or Standard customer

## Technologies
- Python

## Concepts Practiced
- Variables and data types
- User input with `input()`
- Conditional statements (`if`, `else`)
- Loops (`while True`)
- `break` statements
- Arithmetic operations
- Logical operators (`and`)
